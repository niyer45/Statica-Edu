# Original catalog — scoped requirements for the five preview challenges

Task 45.1 additive specification, 2026-10-17. Covers Mounting Bracket I, Torsion Shaft I, Heat Sink I, Braced Frame I and Vibration Isolation I (D-35, D-38). It does not regenerate the completed M0–M3 requirements/design, change Cantilever Beam I, activate a catalog card or integrate dormant Cantilever Beam II (task 52).

Status of every choice below: **proposed developer scope**. Owner engineering review (29.2) has not occurred; no model is implemented; no benchmark has been executed against application code. The numerical values in design.md come from a standalone feasibility calculation for this document, not from human review. Tracks 46.1–50.1 finalize constants and full benchmark worksheets; 45.2 defines the shared contracts that these requirements rely on.

Requirement IDs: `OC-nn` shared, `TS` torsion, `VI` vibration, `HS` heat sink, `MB` bracket, `BF` frame. Design details, equations, references and benchmark plans are in design.md.

## Shared requirements (all five challenges)

- OC-01 Identity: Each challenge has a unique id (`mounting-bracket-1`, `torsion-shaft-1`, `heat-sink-1`, `braced-frame-1`, `vibration-isolation-1`), a configuration version and an explicit model identity/version. Every stored result records the model id/version that produced it. Analysis dispatches on that explicit identity; no non-beam challenge is routed through `eulerBernoulliCantileverTipForce` or shown beam metrics.
- OC-02 Gating: The catalog card stays `available: false` until that challenge's track (46.3–50.3) verifies the complete learning loop. No preview card shows metrics, sample results or a partially working workbench.
- OC-03 Purity: Each model is pure deterministic domain code with the existing import boundaries (no React/Three/UI/state; physics independent of evaluation). UI and state call domain functions and never implement model formulas.
- OC-04 Units: Internal values are SI. Each model declares display units and input parsing (for example degrees, Hz, °C, kN/m). Temperature differences use kelvin internally; displayed absolute temperatures use °C with the stated ambient.
- OC-05 Applicability: Each model defines warning and not-applicable thresholds in its own constants module, evaluated inclusively with the existing `withinLimit`/`REL_TOL` convention. Not-applicable dominates acceptance. Each analysis always lists the model's assumptions and unsupported effects.
- OC-06 Acceptance: A result is Accepted if and only if the model is applicable and every configured constraint passes. Constraint values come only from the stored analysis. Accepted means "meets this educational model's constraints", never real-world approval.
- OC-07 Prediction: The existing increase/decrease/same checkpoint is reused. Each model declares one primary prediction metric (TS twist angle, VI worst in-band transmissibility, HS base temperature rise, MB peak stress, BF roof drift) and the same 0.98/1.02 ratio band unless its 4x.1 specification justifies a different band. If the previous or new result has no finite primary metric (for example a frame mechanism), the outcome is recorded as not scorable rather than invented.
- OC-08 Reflection and explanations: Each challenge has its own reflection prompt. Explanation facts and Guided hints cite only stored values, configured constants and the model's stated limits. The internal reference design is never exposed to students.
- OC-09 Modes: Guided/Parametric are chosen before entry and fixed inside the workbench (D-37). Each challenge provides model-specific Guided steps/hints. Parametric exposes direct editing of the same supported variables. Freeform stays unavailable.
- OC-10 Persistence and import: Drafts, history, deletion metadata, predictions, reflection and submission are isolated by challenge id/version. Saved sessions are re-validated and re-analyzed on load; mismatches are rejected as corrupt. Cross-challenge and cross-model imports are rejected. Existing Cantilever Beam I saves remain valid unchanged.
- OC-11 Validation and failure: Invalid inputs are rejected with typed errors before analysis. A model never returns NaN/Infinity as a result; singular, mechanism or out-of-range states produce an explicit status and no numerical result for the undefined quantity.
- OC-12 Visualization: Every visualization is display-only, derived from stored model outputs, and has a text/table equivalent. The existing non-WebGL fallback principle applies. 3D views follow D-26 (no static overlays on the model). Charts must not convey state by color alone.
- OC-13 Benchmarks: Each model has (a) worksheet fixtures derived outside application code from the cited equations, (b) at least one alternative-method cross-check (different formulation or numerical method), (c) limiting/scaling cases and (d) initial-failure, reference-acceptance and solvability fixtures. Published worked examples may be added only when transcribed with full citation and checked against the source. Tolerances: 1e-9 relative for identical closed forms, an explicitly stated looser tolerance for alternative numerical methods.
- OC-14 Review: Before customer release, each model's constants, equations, thresholds, benchmarks and wording require recorded owner engineering review under 29.2, plus manual/student QA gates. Passing tests is development evidence only.
- OC-15 Card copy: Card title/description/concepts may change only with owner approval, recorded before activation. A scope that cannot honestly support an advertised concept must be resolved by changing scope or copy, not by implying the concept is modeled.
- OC-16 Delivery: Implement in the order recorded in design.md and D-38 (Torsion → Vibration → Heat Sink → Bracket → Frame) unless the owner reorders it. Task IDs and the dependency graph are unchanged; the order is a sequencing choice, not a hard dependency.

## Torsion Shaft I (track 47)

- TS-01 Objective: Learners see that torsional stiffness grows with the fourth power of radius, so moving material outward (hollow tube) achieves stiffness at far lower mass than a solid shaft, within an outer-diameter packaging limit.
- TS-02 Scope: Straight prismatic circular shaft, one end fixed, steady torque applied at the other end, linear-elastic Saint-Venant torsion. Solid circle and circular tube only. Rectangular/I/noncircular sections are excluded from Torsion Shaft I (they need warping/torsion-constant models; bending inertia is never reused as torsional stiffness).
- TS-03 Fixed: length, material (G, E, ρ, allowable shear, yield shear for screening), torque, support. Adjustable: section kind (solid/tube), outer diameter, inner diameter, within configured ranges and minimum wall.
- TS-04 Metrics: angle of twist (deg), maximum shear stress (MPa), mass (kg), polar moment/torsion constant (display), outer diameter (mm). Constraints: twist ≤ limit, shear stress ≤ allowable, mass ≤ limit, OD ≤ packaging limit.
- TS-05 Applicability: shear stress/yield shear (plasticity), tube D/t (thin-wall torsional buckling not modeled), surface shear strain (small-twist assumption; 47.1 TSH-11 shows it is subsumed by the plasticity screen). Exclusions listed: rotating dynamics/critical speed, fatigue, combined bending/axial load, keyways/shoulders/stress concentrations, end-fitting compliance, warping of noncircular sections, plasticity.
- TS-06 Benchmarks: hand J and twist/stress fixtures for solid and tube; tube with zero bore equals solid; thin-wall approximation limit; J = Ixx + Iyy cross-check for circular sections only; linearity in torque/length and 1/G scaling.
- TS-07 Presentation: 3D shaft reusing existing viewport conventions with a display-only twist indicator from the stored angle; SVG fallback cross-section and twist summary.

## Vibration Isolation I (track 50)

- VI-01 Objective: Learners tune isolator stiffness and damping so the component's natural frequency sits well below the operating band (frequency ratio above √2), and see the trade-offs: softer mounts sag more, more damping limits resonance but reduces high-frequency isolation.
- VI-02 Scope: Single-degree-of-freedom linear spring–viscous damper supporting a rigid mass, harmonic base excitation, steady-state frequency response only. No time-history simulation is implemented or implied (task 50.3); resonance passage is screened with steady-state amplitudes and labeled as conservative.
- VI-03 Fixed: component mass, operating frequency band, base excitation amplitude, gravity. Adjustable: total isolator stiffness (from a configured range or mount catalog) and damping ratio via a discrete isolator-material choice with stated ζ.
- VI-04 Metrics: natural frequency (Hz), damping ratio, worst transmissibility across the operating band, peak transmissibility (resonance), static deflection (mm) and peak relative displacement for clearance (mm). Constraints: worst in-band transmissibility ≤ limit, static deflection ≤ limit, peak transmissibility ≤ limit, relative displacement ≤ clearance.
- VI-05 Applicability: damping ratio within the configured viscous-model range (no overdamped/negative); excitation amplitude within the linear-spring range; band entirely defined. Exclusions: multi-DOF and rocking modes, nonlinear/hysteretic mounts, frequency-dependent stiffness, shock/transients, support flexibility, acoustic paths.
- VI-06 Benchmarks: closed-form transmissibility fixtures; r = √2 gives TR = 1 for all ζ; undamped limit; exact peak location/value formula; static-deflection/natural-frequency identity; alternative check by numerically integrating the ODE to steady state in test code.
- VI-07 Presentation: spring–mass schematic plus a frequency-response chart computed from the model with the operating band marked and a table equivalent. The chart is a new accessible component; no animation implies simulated motion.

## Heat Sink I (track 48)

- HS-01 Objective: Learners see that adding surface area lowers temperature, with diminishing returns from fin efficiency and a mass/space budget, and that a model limitation (spacing) bounds unrealistically dense fins.
- HS-02 Scope: Steady-state plate-fin heat sink, uniform heat input over the base footprint, base conduction resistance, straight rectangular fins with corrected-length tip condition, specified uniform effective convection coefficient, overall surface efficiency. Radiation, spreading resistance and spacing-dependent convection are excluded and disclosed.
- HS-03 Fixed: footprint, heat load, ambient temperature, effective convection coefficient, material, base thickness (or an owner-approved adjustable base). Adjustable: fin count, fin thickness, fin height, within ranges and a minimum manufacturable gap.
- HS-04 Metrics: base temperature (°C) and rise (K), total thermal resistance (K/W), fin efficiency, overall surface efficiency, mass (g), fin gap (mm), height (mm). Constraints: base temperature ≤ limit, mass ≤ limit, height ≤ envelope, gap ≥ minimum.
- HS-05 Applicability: fin Biot number (1D fin assumption), fin gap versus the spacing below which a constant coefficient is unsupported (not applicable) or questionable (warning), fin aspect ratio. Exclusions: radiation, spreading resistance, flow bypass, spacing/flow-dependent convection, interface resistance (unless configured), transient warm-up, temperature-dependent properties.
- HS-06 Benchmarks: hand fin efficiency/resistance fixtures; energy balance (sum of fin and base convection equals heat load); h → 0 and k → ∞ limits (η → 1); alternative check by finite-difference 1D fin conduction in test code.
- HS-07 Presentation: 3D/SVG fin array; any temperature coloring is derived from the stored fin profile and duplicated in text. No flow animation.
- HS-08 Owner decision: whether Heat Sink I uses a specified effective (fan-assisted) coefficient with a minimum-gap rule (recommended) or a natural-convection spacing correlation (more realistic, adds temperature-dependent iteration). Record before 48.1 is completed.

## Mounting Bracket I (track 46)

- MB-01 Objective: Learners find where the stress actually peaks along a bracket and reduce it by redistributing material and softening a sharp transition, rather than by adding mass everywhere.
- MB-02 Recommended scope: Planar stepped flat-bar cantilever bracket of rectangular cross-section, fixed at the wall, in-plane tip load. Nominal Euler–Bernoulli bending stress at the root and at the shoulder step; at the step, multiply by a published stepped-flat-bar shoulder-fillet stress-concentration factor fit within its stated range. Stepped-cantilever tip deflection from closed-form integration. Kt never applies to deflection.
- MB-03 Fixed: total length, load, material, thickness (or owner-approved adjustable thickness), mounting. Adjustable: root depth, arm depth, step location, fillet radius, within ranges that keep every Kt parameter inside the fit's validity range.
- MB-04 Metrics: peak stress and its location (root or step), Kt at the step, nominal stresses at both checked sections, tip deflection, mass, envelope. Constraints: peak stress ≤ allowable, deflection ≤ limit, mass ≤ limit, envelope.
- MB-05 Applicability: Kt fit parameter ranges (outside → not applicable), peak stress/yield, depth/span (shear), depth/thickness (lateral buckling). Exclusions: wall-clamp and bolt-hole concentrations, fastener/joint compliance, fatigue, plasticity, 3D and out-of-plane loading, contact.
- MB-06 Benchmarks: hand nominal stress and stepped-deflection fixtures; uniform-depth limit equals the existing beam formula for a rectangle; Kt fit values compared with transcribed chart readings within a stated tolerance; critical-section switching cases.
- MB-07 Owner decisions: (a) approve the chart-fit stress-concentration approach (recommended) versus a knee-braced statics bracket (load-path emphasis, no concentration) or deferral pending a more capable solver; (b) approve concept copy (keep "Load paths, Stress concentrations" interpreted as the internal bending-moment path, or revise). Record before 46.1 is completed.

## Braced Frame I (track 49)

- BF-01 Objective: Learners trace how lateral load travels through members, discover that a pin-jointed frame without bracing is a mechanism, and strengthen only the members that govern.
- BF-02 Scope: 2D linear-elastic pin-jointed braced frame (truss idealization of a simply connected braced frame) solved by the direct stiffness method, small displacements, from a fixed configured template (proposed: one bay, two storeys, pinned bases, candidate diagonals per storey).
- BF-03 Fixed: geometry template, supports, loads, material. Adjustable: which candidate diagonals exist; member sizes from a discrete section catalog.
- BF-04 Metrics: roof drift and inter-storey drift ratio, member axial forces (tension/compression), maximum member utilization (tension yield; compression lesser of yield and Euler buckling with pinned ends), mass, stability status. Constraints: drift ≤ limit, utilization ≤ 1, mass ≤ limit, stable structure.
- BF-05 Mechanism/singularity: a singular or near-singular stiffness matrix (configured pivot tolerance) is reported as an unstable mechanism with no displacements or member forces and is never Accepted.
- BF-06 Applicability: compression slenderness below the inelastic transition (Euler overestimates; warning), drift ratio (small-displacement assumption). Exclusions: rigid/semi-rigid joints and frame bending, P-Δ/second-order effects, tension-only bracing behavior, connection design, imperfections, dynamic/seismic response, self-weight unless configured.
- BF-07 Benchmarks: method-of-joints hand fixtures for determinate braced cases; force-method fixture for one redundant (X-braced storey); global equilibrium of reactions; linearity in loads and 1/E displacement scaling; unbraced-storey mechanism fixtures.
- BF-08 Presentation: accessible 2D frame view with keyboard-operable diagonal toggles/size selection, tension/compression shown by pattern and text (not color alone), table of member forces.
